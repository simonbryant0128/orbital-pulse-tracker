# 內容資料庫

Google Sheets 雲端主表保存候選事件與審核狀態，網站只讀取 GitHub `main` 分支中的已發布資料。官方且無衝突的資料可以標記為「自動查證」；來源不清楚或互相衝突的資料標記為「待人工確認」，不會直接發布。通過審核的資料形成分支／Pull Request，經格式、重複 ID、日期、公司名單與來源網址檢查後才可合併。

## 檔案

- `events.json`：發射、部署、時程、異常、合約與里程碑；每筆包含摘要、詳細內容與原始來源。
- `constellations.json`：星系公開檢查點、部署總量、下一次官方任務與歷史版本快照。
- `programs.json`：Starship、Neutron、New Glenn 的計畫狀態。
- `companies.json`：追蹤公司、股票代號、關注範圍與官方來源。
- `weekly/`：每週摘要。
- `meta.json`：網站名稱、最後核對日期與資料政策。

每筆事件都必須有穩定 ID、日期、公司、狀態、摘要、詳細內容，以及至少一個可開啟的來源網址。部署資料中的下一次日期只採公司官方排程；若尚未公布確切日期，以 `null` 保存並在網站顯示「待官方公告」。不要在沒有留下更正紀錄的情況下覆蓋歷史事件。

## 人工確認

在雲端主表的 `網站事件_主檔` 分頁處理：把「審核狀態」改為 `已確認`，再把「網站發布」改為 `待同步`。下一次自動更新會將符合條件的事件送入 GitHub 檢查流程；`待人工確認` 與 `不發布` 不會出現在網站。
